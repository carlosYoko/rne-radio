# Logos de las emisoras

Los seis SVG son copias locales de los identificadores publicados por RTVE en su web. Son versiones blancas, por lo que se presentan sobre fondo oscuro.

Fuente: `https://css2.rtve.es/css/rtve.2021/i/rtve-logos/logos_cadenas/`

| Emisora | Archivo de origen y archivo local |
| --- | --- |
| Radio Nacional / RNE | `radio-nacional.svg` |
| Radio 3 | `radio-3.svg` |
| Ràdio 4 | `radio-4.svg` |
| Radio Clásica | `radio-clasica.svg` |
| Radio 5 | `radio-5.svg` |
| Radio Exterior | `radio-exterior.svg` |

Los archivos se conservan sin modificar. No contienen scripts ni referencias a imágenes o recursos externos. Los iconos PNG de la barra combinan el logo blanco de cada emisora con un fondo rojo añadido para asegurar contraste. El icono general de la extensión utiliza RNE; el de la barra cambia dinámicamente con la selección.

Los logos y las marcas son propiedad de sus respectivos titulares. Su inclusión identifica las emisoras y no implica que esta extensión sea oficial ni esté avalada por RTVE. No se presupone una licencia de libre redistribución: antes de publicar en una tienda, comprueba las condiciones de uso de las marcas y obtén autorización si corresponde.
